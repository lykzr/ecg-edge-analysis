## 已确认的数据路线



`ADS1292R → STM32 → JDY-18蓝牙 → 配套USB接收适配器/电脑 → 板载USB_UART → Zynq`；Zynq经同一USB_UART把运算结果返回电脑。采集侧至电脑无线，电脑至Zynq仍为USB_UART；两个连接分别识别端口，不固定COM4。电脑保存/显示原始数据并中转，Zynq执行板端运算；不把PC运算替代ARM/FPGA对比。具体适配器身份及实际负载仍待联调。

## 检索结论与工程含义

1. 模型/规则选择本身也会过拟合。原42条MIT记录全部参与过迭代，统一作为已知开发回归；不得重分后称新独立测试。患者级分组和预处理训练折拟合继续保留；开发折用于选型时不称最终独立测试。需要时内层调参、外层评价；旧已查看数据做嵌套也不能恢复未触碰资格。来源：[Cawley与Talbot](https://www.jmlr.org/papers/v11/cawley10a.html)、[官方分组说明](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-iterators-for-grouped-data)、[嵌套评估](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)。
2. 105官方说明有严重噪声和伪迹。优先受控噪声实验，比较同一段输入干净/加噪后的TP/FN/FP、V召回、定位/RR及恢复。不得删除噪声段或用未知/拒绝输出掩盖分母。官方NST已有118/119的12个电极运动加噪版本，24/18/12/6/0/-6dB；它们基于已知开发患者，不是独立测试。来源：[105目录](https://physionet.org/physiobank/database/html/mitdbdir/records.htm)、[NST库](https://physionet.org/content/nstdb/1.0.0/)、[校准说明](https://physionet.org/physiotools/wag/nst-1.htm)。自制bw/ma混噪必须另立协议明确校准，不能把普通RMS比冒称官方QRS幅值SNR；先用官方em版本核对再扩展。
3. CNN低分不直接证明训练过拟合；用相同自然分布/指标口径比较训练和验证逐类/患者分数、损失和学习曲线，区分优化失败、数据覆盖、域差异与泛化差距。训练加权loss和验证未加权loss不能直接比较差值。来源：[学习曲线](https://scikit-learn.org/stable/modules/learning_curve.html)。已有AdamW、权重衰减、余弦下降、早停、类别加权、时间/幅值/白噪声增强，不能作为新方法重复试。
4. Class-Balanced Loss可作为现有加权损失的一项小规模对照，原研究为图像长尾数据，未证明对本项目有收益。不同时叠加多种采样/损失改动。F拍集中少数患者时优先审查不同患者覆盖，重复采样不能制造新患者多样性。来源：[作者代码与论文](https://github.com/richardaecn/class-balanced-loss)。本计划只列候选，CNN训练暂停状态不解除。
5. 比较公开模型须核对任务、患者条件、导联、标签、输入窗口和许可。经典患者专用1D CNN使用目标患者部分训练数据，不能继承为新患者泛化成绩。来源：[原论文摘要](https://pubmed.ncbi.nlm.nih.gov/26285054/)。切拍同时保留专家位置分类与自动检测端到端两种评价，后者不得借专家位置补漏检。
