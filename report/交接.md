# 工程交接

供首次接手该工程的开发者使用。所有命令从工程根目录执行，安装路径、串口、下载器和硬件修订均使用接手者自己的实际值。无需原作者电脑、聊天、历史tmp或私有厂商CSV。先按使用步骤运行，再按剩余任务继续开发。

## 拿到的工程能做什么

| 内容 | 当前发布范围 | 接手时的含义 |
| --- | --- | --- |
| PC客户端 | 演示、日志回放、原码接收/保存、USB_UART双向中转 | 可先无板启动，不在PC上执行QRS或CNN |
| runtime500 | 新500Hz ARM QRS、切拍、RR及双向通信 | 采用500Hz、4096单位/mV；分类后端NO_MODEL，不输出有效N/S/V/F |
| smoke | 原PL检测器/AXI/FIFO的独立合成自检 | 是回归应用，与新ARM检测器和完整CNN分开 |
| bridge | 旧PL检测器数字回放 | 仅显式legacy500使用，不作为当前厂商接入默认 |
| qspi | 匹配FSBL、BOOT.BIN、编程/复位脚本 | 仓库有镜像不代表接手者的Flash已写入，默认检查不操作硬件 |
| skill | 三项可复用校验/诊断技能 | 可独立复制，见[技能入口](../skill/README.md) |

当前预制镜像针对领航者V2 Zynq-7020，构建ID a570b308ef7b46fe。另一型号、核心板/底板修订或硬件配置未经核对，不能直接烧录。正式目标仍包含滤波、工频抑制、轻量CNN/INT8/FPGA推理与ARM性能比较，尚未完成。

目标数据路线为ADS1292R→STM32→JDY18→USB接收器→电脑→USB_UART→Zynq→电脑；PC保存原码、去直流/标称换算和中转，QRS/切拍在ARM，最终CNN目标在PL。厂商34字节、PC输入ECG-IN-1、结果ECG-UART-1分别定义，不能混用。

## 第一次使用：没有板卡也能开始

1. 确认拿到包含本页及releases/latest的完整工程，在自己的短英文路径打开，例如C:/work/ecg_edge。本工程不含Python环境、AMD工具、原始ECG、官方手册或历史缓存；这些按用途另备。如文件不完整，请向工程提供方确认版本与获取方式。
2. Windows准备带Tkinter的Python。客户端基础功能使用标准库；完整测试环境采用Python3.14及固定依赖，另需已有GCC。先在PowerShell切到工程根目录。
3. 不连接板卡，检查文件和发布一致性：

```powershell
python -B sim/check_checkout.py
python -B sim/check_system_release.py
powershell.exe -NoProfile -ExecutionPolicy Bypass -File releases/latest/qspi/program_qspi.ps1 -CheckOnly
```

三条均应成功；缺文件或SHA不符先重新取得完整版本，不修改清单让它强行通过。

4. 启动`python -B src/ui/main.py`。点“开始演示”，应出现合成波形和演示标记；点“停止并保存”，状态栏给出本次目录，选择其中raw.log可回放。演示标记不是检测结果，“未提供”不是正常N。窗口与保存说明见[客户端教程](../docs/pc_monitor.md)。
5. 没有采集器时，可以做演示/已有日志和公开标准CSV验证；厂商CSV不随仓库分发，不需要向原作者索取私有历史tmp才能开始软件开发。尚无输入CSV时先完成无板步骤，不把演示raw.log直接当标准CSV上传。

## 接自己的板卡：选择一种运行方式

先核对具体板卡、供电、BOOT_CFG、下载器唯一序列号和USB_UART身份。不能照搬原作者COM14或JTAG号；也不要同时让终端/Vitis和客户端占用同一个串口。[下载教程](../docs/download_guide.md)给出完整参数与成功判据。

- 临时JTAG：按匹配板级资料设置启动方式，连接并上电，双击releases/latest/runtime500/download.cmd，填写自己已安装的XSDB路径和唯一JTAG序列号。检查/初始化/下载成功后再打开客户端。它不写Flash，不能保证掉电保存这次修改。
- QSPI持久启动：只有已经将本版匹配镜像写入自己板卡后才适用。编程需操作者明确决定覆盖旧镜像；按教程显式使用releases/latest/qspi/program_qspi.ps1 -Program，程序默认只检查。编程Verify、实际启动模式与彻底断电启动须分别验证。相同领航者启动表为JTAG 1=ON、2=ON，QSPI 1=ON、2=OFF，按实物编号和ON丝印复核；其他板禁止照搬。
- QSPI每轮有限会话结束后：已固化的板卡用PS复位键重新就绪，不是PS_KEY1；通常无需重复写Flash。若仅JTAG临时运行则使用对应下载流程，不推断其复位可自启动。

客户端主窗口串口保持未连接，打开“送样/双向中转”，只在子窗口选择Zynq USB_UART。标准500Hz文件使用index,sample,fs,scale且fs=500、scale=4096；厂商五列RawData使用厂商CSV入口，CH2去直流/标称换算在内部执行。蓝牙接收器是另一个端口。串口参数115200/8N1/无流控，编号按本机识别并核对身份。

数字闭环通过条件为上传=确认=回传、正常完整结束、无解析/序号/队列错误；事件/窗口需与同源参考核对，不能只凭有波形验收。保存本次目录和应用身份。真实JDY18、物理拔插、实际标定与最终分类仍待测试。

## 开发与重建：按需准备依赖

以下命令供接手者在自己的授权环境执行，不要求修改系统Python：

```powershell
py -3.14 -m venv tmp/system_env
./tmp/system_env/Scripts/python.exe -m pip install -r data/requirements_system.txt
$env:ECG_HOST_CC = '<已有GCC的gcc.exe完整路径>'
./tmp/system_env/Scripts/python.exe -B sim/check_system_offline.py --output tmp/offline_new --clean-copy
./tmp/system_env/Scripts/python.exe -B -m unittest discover -s sim -p test_system_release.py
```

输出目录必须尚不存在。不要对sim盲目通配全部测试，部分入口需Torch、Vivado或实际板卡；当前系统离线入口已选择依赖范围。Tk隐藏窗口测试不替代人工视觉。

只改Python客户端无需重建bit/ELF。改板端代码、硬件或量化后，用自己的已安装工具完整重建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File board/rebuild_system.ps1 -Output tmp/rebuild_new -VivadoBin '<Vivado>/bin' -VitisBin '<Vitis>/bin' -Python '<测试环境/python.exe>' -Rate 500 -Trace 0
```

bit/XSA/init/FSBL/ELF取自同一清单；正常运行Trace=0，完整窗口调试另建Trace=1，不拿调试带宽报性能。其他板PS7/DDR/MIO/时钟必须按资料核对，不能套预设。

只重新打包已发布启动镜像，不需原构建工作区：

```powershell
python -B board/prepare_qspi.py --release releases/latest --bootgen '<Vitis>/bin/bootgen.bat' --output tmp/boot_new
```

这条只生成文件、不写板卡。公开数据全记录准确率回归另按[data说明](../data/README.md)获取数据；模型训练入口和独立患者限制见[模型交接](../docs/model_training_handoff.md)。

## 接手时必须保留的边界

- 500Hz源输入保持500Hz；内部适配与500Hz事件/源时轴分开，不能要求采集端改360Hz。当前阶段只是开发回归与有限数字实板，不是临床设备或独立泛化合格。
- 原105风险与全部失败证据保留。不要把计划里旧失败/已被后续完成项覆盖的未勾框当新任务重跑；当前优先级看本页，再到专题计划/记录追溯。
- 新QRS在ARM，既有PL原检测器/AXI/FIFO用于独立smoke，PL尚无CNN。部分旧源码注释曾写“送PL”，以实际调用/BD和当前说明为准，不为了改一条注释伪改已验ELF来源。
- 根README.md、docs/materials_review.md不随整理改；用户数据/历史/备份不删除，工具派生与失败留tmp，不复制到Git。
- report是计划/报告，docs是操作/协议，docs/records是过程/验收，model是训练，src是正式实现，board/build/sim是运行/构建/验证入口，releases只保留当前交付文件，history本地忽略。
- 匹配镜像和源码SHA是发布门禁；改功能后新建证据与版本，旧latest原样归档。Flash编程必须获得操作者授权；QSPI复位不写Flash，但不能当第二次物理冷启动。
