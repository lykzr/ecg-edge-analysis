# 网页集成计划

采用来源项目的网页界面，保留本项目已验的采集、双向中转、原始记录与诊断入口；不改变心电系统、CNN/INT8/FPGA推理和ARM/FPGA对比目标。当前模型研究合并仍按[模型合并计划](model_merge.md)推进。

## 范围与验收

- [x] 独立merge分支中导入指定提交的网页/离线业务，保留来源路径和原始哈希；原分支保持不变。首次集成仅本地保留，后续提交按用户当次授权执行。
- [x] 网页增加演示、原日志、只收Zynq、厂商CSV/蓝牙查看与中转、360/500Hz标准CSV入口，复用原后台及协议。
- [x] 来源和结果波形、事件、未知字段、缺口、停止保存、SVG/文件下载、端口USB身份记忆、账户隔离和会话历史的软件检查。
- [x] 修正未知室早显示0、抽稀时间错位、实时WebSocket空入口、无限内存分析队列、默认工作目录与模型依赖问题。
- [x] 独立环境、前端类型检查/构建、后台回归与同源C核心的模拟双串口检查；教程和记录分别维护。
- [ ] 在实际浏览器检查常用分辨率、缩放、表格和操作反馈；不以静态构建冒充视觉验收。
- [ ] 用本次网页执行真实无线→电脑→Zynq→显示保存、双USB拔插、断连恢复和持续运行；旧客户端/固件的历史成功不能直接继承为网页通过。
- [ ] 取得上游明确再分发许可，完成网页最终发布与接手者复验；本轮不替换冻结latest。
- [ ] 接入经确认的最终模型及其特征/窗口/标签合同，再完成模型实测、INT8与FPGA部署和性能比较；本轮无训练、无假分类。

## 分工和边界

网页进程保存与显示，现有PC后台解码厂商34字节/CSV并规范送样，板端按既有USB_UART合同运算。独立离线记录的滤波和可选OpenECG不混入实时数据路径。不采用来源STM32固件脚手架或未落实的新硬件协议，不写Flash、不改供电/PS7/MIO，不自动启动原客户端。

使用入口见[网页教程](../docs/web_monitor.md)，实际结果见[本轮记录](../docs/records/web_merge_20261031.md)。
