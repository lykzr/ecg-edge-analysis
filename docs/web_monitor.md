# 网页客户端使用说明

网页沿用 `health_system-v2` 的青绿色界面、记录详情、趋势、备注和家庭授权功能；新增“实时与板卡”，连接本项目现有采集、中转与保存后台。来源及许可边界见[第三方说明](../src/web/NOTICE.md)。原[Tk客户端](pc_monitor.md)与命令行入口保留，串口不能同时被两个客户端占用。

## 启动

从项目根目录执行。本机已按授权建立 `tmp/web_env`；以下安装命令用于新环境，不会在启动时自动安装。

```powershell
python -m venv tmp/web_env
& ./tmp/web_env/Scripts/python.exe -m pip install -r src/web/requirements-lock.txt
./build/build_web.ps1
& ./tmp/web_env/Scripts/python.exe -B src/web/run.py
```

浏览器打开 `http://127.0.0.1:8000`，首次先注册本地账号，密码至少8位，再登录并进入“实时与板卡”。服务默认仅监听本机、单进程；端口占用可在启动命令末尾加 `--port 8001`。关闭时在启动终端按 `Ctrl+C`，等待保存和串口关闭后退出。

锁定依赖是在 Windows/Python 3.14、Node 24 上验证的版本。其他 Python 版本若无法安装锁定版本，可由负责人在独立环境用 `src/web/requirements-dev.txt` 解析兼容依赖，并重新跑测试，不能直接继承本机结论。前端由脚本复制到 `tmp/web_frontend` 后安装、构建；源码留在 `src/web/frontend`，依赖和 `dist` 不进入Git。已有依赖仅重建时使用 `./build/build_web.ps1 -SkipInstall`。

## 选择来源

| 方式 | 输入与行为 |
| --- | --- |
| 合成演示 | 数学波形和预设事件，默认360Hz；不执行QRS/CNN |
| 日志回放 | 本项目接收记录的 `raw.log`；按原序号、会话头解释，读取速度不当采样率 |
| 只接收Zynq结果 | USB_UART 115200/8N1/无流控，只读 `ECG-UART-1`，不自动复位或下载 |
| 厂商CSV查看 / 蓝牙查看 | 严格厂商CSV或已确认34字节帧；CH2为ECG，CH1为呼吸，保留原码及厂商滤波列 |
| 厂商CSV / 蓝牙→Zynq | 500Hz厂商路线，复用CH2标称换算、去直流和现有 `runtime500` 中转 |
| 标准360 / 500Hz CSV→Zynq | `index,sample,fs,scale`，索引从0连续，采样率严格匹配，`scale=4096`，样本为int16；不当作厂商原码 |

文件上传上限32MiB。厂商原码、电脑送样 `ECG-IN-1`、Zynq返回 `ECG-UART-1` 分别解析，不混用帧。输入合同、板端应用、复位与下载步骤继续查[厂商输入](vendor_input.md)、[中转协议](bridge_protocol.md)与[下载教程](download_guide.md)。网页不写Flash，也不自动下载固件。

点击“刷新端口”只枚举设备，不打开串口。下拉框显示USB名称；设备合法报文确认后，沿用 `tmp/pc_devices.json` 记忆USB实例身份，COM变化时跟随身份。采集接收器和Zynq必须选择不同端口；启动前再次核对USB身份。只有枚举结果不能证明该设备正在发送正确数据。

## 画面、保存与重看

点击“开始并记录”；来源和结果分开显示。来源可选CH2/CH1、原码/厂商滤波列；标准输入只显示其本身。结果可选raw、filt或二者叠加，缺失字段不补零、不假造正常类别。采样率未知时使用样本号横轴；比例未知时显示码值。波形按源时刻抽稀、缺口断线，事件仅标到实际收到的位置。

“暂无新串口字节”只表示接收陈旧，心率等仍是上次值，不证明物理断连。停止后画面为历史数据。点击“停止并保存”，等待后台关闭；在“诊断与保存文件”下载原始日志、CSV、摘要，或导出当前结果SVG。页面显示最多4096点、256个事件，完整记录在文件内；采集和中转的原有有界队列及64MiB记录限制继续生效。

关闭页面、切换页签、刷新或退出登录不会擅自停止服务端采集。重新登录后进入“实时与板卡”，从会话列表选择正在运行的会话再停止。列表返回本人最近100个会话，完成后的索引与快照落盘，服务重启后可查；上传凭证只在本次服务运行中有效，重启后重新上传。

数据默认位于 `tmp/web_runtime`：`health.sqlite3` 与离线上传是原网页业务；`live/uploads` 是实时输入副本；`live/sessions/<编号>` 是每次采集、回放和中转的完整记录。上传副本累计限制256MiB/64个文件，达到后先确认无活动会话，再由使用者整理上传缓存；程序不自动删除旧数据。HTTP请求实际字节另有限额，分块发送也受限。可用进程环境变量 `HEALTH_DB_PATH`、`ECG_UPLOAD_DIR`、`ECG_WEB_LIVE_DIR` 选择自己的数据位置。

## 离线记录与模型边界

“导入与分析”是独立的离线记录流程：支持单列mV或带 `ecg_raw` 的厂商CSV，提供零相位显示滤波、质量初检、记录查询、趋势、备注、导出和家庭授权。该滤波会使用未来数据，不能当实时板端处理。默认模型为 `none`、解释为本地模板，不安装或自动调用OpenECG/外部AI。

网页导入的OpenECG适配与本项目模型分支不是同一套模型，也不共享标签或成绩。可选OpenECG仅适配严格500Hz且至少10秒的记录，目前只分析前10秒，尚未验收。当前模型分支的192维特征生成与生产适配仍待完成，网页不伪造已接通分类。

厂商离线电压换算沿用本项目冻结的 `ads1292-ch2-nominal-v1` 合同：2.42V、增益6、分母8388607。TI理想LSB通常以8388608表述，两者相差约0.000012%；这里明确保留合同以匹配既有送样，不能称重新完成物理标定，也不能把零相位离线滤波再当作中转去直流。完整原码始终保留。

## 验证与限制

```powershell
& ./tmp/web_env/Scripts/python.exe -B -m pytest sim/web -q -p no:cacheprovider
node --experimental-strip-types --test sim/web/waveform.test.mjs
./build/build_web.ps1 -SkipInstall
```

C链路测试使用已有GCC，必要时设置 `ECG_HOST_CC`；不自动安装编译器。波形逻辑、HTTP/WebSocket、模拟串口与实际PS C核心的软件检查不替代浏览器人工视觉、真实无线、双USB、拔插或长时实物验收。具体本轮结果见[集成记录](records/web_merge_20261031.md)。

来源网站的账号和历史数据库没有迁移，本地首次使用需注册新账号；这不表示原数据已被删除。当前浏览器采用串行HTTP轮询，后台WebSocket另有接口。实际浏览器操作、实物联调、模型接入与许可等未完成项集中见[网页集成计划](../report/ui_merge.md#当前未完成项与行为差异)。
