# CLEF-Small备选：预训练迁移

状态：已保存的备选路线，暂不实施。主线为复用公开轻量1D CNN结构、训练心拍分类基线；具体任务和进度见[工程计划](../../report/project_plan.md)。

## 用途与来源

CLEF-Small是单导联ECG预训练表征候选，拟通过增加分类头并微调适配本项目心拍分类。它不是已经适配N/S/V/F的即用分类器。来源核查、日期与其他方案比较见[模型调查](../records/cnn_model_survey_20261016.md)。

- 作者仓库：[Nokia Bell Labs ECG foundation model](https://github.com/Nokia-Bell-Labs/ecg-foundation-model)。
- 作者权重入口：[Zenodo记录](https://zenodo.org/records/17572734)。

本文件保存方案和恢复检查项，不存模型二进制。以后若下载权重，放独立tmp目录并核对来源、许可、文件大小和哈希；经确认交付的权重再按发布规则处理。

## 恢复此方案时的顺序

1. 核对作者仓库和权重条款，区分代码许可与权重许可，确认归档仓库的兼容性与维护成本。
2. 检查真实网络结构、采样率、输入长度、导联、滤波和归一化；决定整段表征是否适合单心拍任务，不先强行套256点窗口。
3. 检查预训练数据是否包含拟用测试受试者；有重叠时修改评估口径，不能宣称未见数据泛化。
4. 在独立环境做最小加载与推理，保留版本/哈希；再使用与主线相同的冻结分类协议评估迁移效果。
5. 统计算子、参数、MAC与激活缓存，再决定电脑端对照、蒸馏或部署用途；checkpoint大小不能替代7020资源预算。

## 何时再考虑

主线获得可复现基线后，若逐类表现仍不足且时间、资源允许，再评估预训练迁移是否有收益。当前不为此安装依赖、下载权重或占用训练；恢复工作依用户后续安排。
