# ECG AXI-Lite 寄存器与事件消费

基地址 `0x43C00000`，32 位总线，仅支持下表中完整、4 字节对齐的相对地址。未实现/未对齐地址返回 AXI `SLVERR`；不会镜像到低地址寄存器。向只读地址写入也返回 `SLVERR`。

| 偏移 | 权限 | 含义 |
| --- | --- | --- |
| 0x00 | 写；读为 0 | 低 16 位有符号样本，WSTRB[1:0] 都为 1 才提交一个样本 |
| 0x04 | 读/写 | bit0 为 FIFO 非空；写 1 弹出队首。bit1 为溢出提示，写 1 清除提示 |
| 0x08 | 读 | 队首事件的 QRS 样本位置；空队列为 0 |
| 0x0C | 读 | 同一队首事件的 RR 间期（样本数）；空队列为 0 |
| 0x10 | 读 | 当前积分能量（调试值，会变化） |
| 0x14 | 读 | 当前检测阈值（调试值，会变化） |
| 0x18 | 读 | 队首事件序号，从 1 开始；空队列为 0 |
| 0x1C | 读 | 排队事件数 |
| 0x20 | 读 | 累计丢弃事件数，复位清零 |
| 0x24 | 读 | 配置的采样率 Hz |
| 0x28 | 读 | 配置的积分窗口 ms |
| 0x2C | 读 | 配置的不应期 ms |
| 0x30 | 读 | 总检测事件数，包括 FIFO 满时丢弃的事件 |

FIFO 默认深度为 8，锁存事件位置、RR 和序号。新事件不会修改已排队事件。软件应由一个消费者读取 bit0，依次读取 0x08、0x0C、0x18，然后写 0x04 bit0=1 消费一个事件。读取中不要提前弹出；其他程序也不应并发消费队列。

队列满时保留已有事件、丢弃新事件，同时置溢出 bit1 并累计丢弃数；同周期消费旧事件和产生新事件可正常入队。清除溢出提示不会清除累计丢弃数。计数器为 32 位，到上限自然回绕。

采样率、窗口和不应期通过 `ecg_qrs_axi_lite` 参数传给检测器，不支持运行中直接写寄存器改变。默认 360 Hz、120 ms、200 ms。构建 BD 前可设置 Tcl 变量 `ecg_sample_rate_hz`；接入真实采样或数据回放前必须核实采样率，不能按 FPGA 时钟频率推算 ECG 采样率。

这是 QRS 候选检测接口，没有宣称真实心电精度或板上验证完成。
