日期：2026-11-01。基线为merge/6dfe5eb907ed5da0480c8f7ef38ddfc71fd9c944。用户确认本轮完成电脑HGB与网页联调，ARM移植另做，并允许仅在联调专用环境安装依赖。没有训练、读取保留患者、操作设备或修改固件镜像。

## 本次实现

默认模型改为仓库HGB v92/fold0；none仍显式关闭，OpenECG仍为独立可选节律适配，不自动替换或投票。HGB以独立进程处理完整连续记录，调用原500Hz检测、切拍、192项特征及固定权重；每次重新建立全部状态，4数值线程、180秒超时、最多200000点。权重和完整model/inference资产均未修改。

采集结束回调等待来源/串口/文件关闭，读取完整CH2原码记录，按既有2.42V/增益6合同换算mV→hp05，不使用厂商滤波列、网页零相位滤波或4096点显示缓存。标准500Hz输入须明确hp05/raw；没有声明、序号/时间不连续、失败、超限或中转未DONE/来源-确认-回显不一致则拒绝，不补点、不截断。原始硬件没有样本序号时，不宣称无线无丢样。

任务和会话关联持久化，重复提交复用任务，账户隔离沿用现有服务。网页显示逐拍N/S/VF、未分类、位置、概率与板端事件关联；固定±25点双向唯一才关联，不拟合偏移或强配，保留双方位置和板端原类别。N不表示健康，VF为V/E/F合并，不表示心室颤动；模型不可用不显示零异常。

## 范围和剩余项

这是采集结束后整段分析，不是逐块在线分类。固件依旧NO_MODEL/?，HGB实际运算在电脑；没有ARM模型移植、INT8/PL推理、新板卡镜像或板上性能验收。没有真实ADS/人体输入、人工浏览器视觉操作或完整临床质量验收；模拟串口与真实C核心不能冒充实物。全部验证输入为合成数据，不提高或重新声称研究模型质量。

启动、输入合同、错误重试、配置和界面入口见[模型接入](../model_integration.md)。旧src/web/.env明确设置none时仍关闭分类，需要改hgb后重启；网页环境与模型环境不一致时用ECG_HGB_PYTHON指定已通过完整自检的模型Python。main及原feature/ecg-model不随此次提交移动。
