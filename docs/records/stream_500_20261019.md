# 500Hz独立流式候选适配记录

## 目标与版本

2026-10-19，用户要求处理例程500Hz与当前360Hz候选的采样率差异；传输方式留待讨论。本轮将独立PS/PL合成流默认改为500Hz，保留已通过的360Hz smoke、latest和旧工作区。不更改真实ADS1292R寄存器、供电/引脚、模型输入或公开数据协议，尚无板卡在手。

**34字节/10字节是附带通信协议DOCX与main.c的差异，不是TI芯片PDF的数据格式冲突。** 两版先保留记录，不决定Zynq直连/STM32桥接，不把原厂二进制帧混入现有ECG-UART-1文本流。

## 修改与理由

- stream.h默认ECG_STREAM_RATE_HZ=500；stream.c统一调度分母、每秒合成脉冲、H/T采样率、算法窗口标识与心率计算。名义心率为60*fs/RR，不能沿用360Hz的固定常数。
- 初始化核对PL只读参数500Hz/120ms/200ms，不匹配即CONFIG_MISMATCH且不送样，防止把旧360Hz bit与新PS混用。120ms积分窗为60点，200ms不应期为100点；不改原检测器算术、阈值或默认360Hz参数。
- 新增build/stream_500.tcl，复用领航者生成器并显式传500，在新的tmp/ecg_stream_500构建；不修改正式共享工程。Vitis脚本默认读取这里的匹配XSA/bit/ps7_init，默认5003点，约10.006秒名义时间，上限1800000点只是整数预算，不是一小时实测。
- 参数化现有RTL自检，默认仍为360；增加500Hz顶层，验证真实AXI写样、检测器与FIFO。主机假外设另跟随采样率，单独保留360Hz兼容编译检查。
- 同步PS说明、UART实现版本说明、采集/主体计划和交接清单；第一条传输差异记为待讨论。不改报文字段结构、PC实现、smoke应用、latest或训练配置。
