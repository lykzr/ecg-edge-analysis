# 心跳原波形确认与误检改进

2026-10-21，用户在了解QRS是给CNN定位/截取心拍并计算心率/RR之后要求继续修改。本轮目标是改进上轮原码auto候选的误检和位置；继续离线，不恢复CNN训练、Git、板卡或Flash操作。原版及上轮候选的源码/工具工程/镜像、已验发布和模型基线均保留。

## 依据与方法

读取ecg_auto.py、原能量RTL、ecg_qrs_v4.py、gqrs_stream.py、公共滤波/解码/计分函数及上一轮逐记录结果。原auto能量位置只是窗口中心，噪声/宽波也能触发；既有软件v4已有原波形极值定位、中心/背景质量及近邻宽波救援，因此本轮先在独立ecg_peak.py复用这些思路，不盲目调阈值或重写旧冻结算法。

每次实验在输出前保存规则与来源，记录相同19条完整开发记录（每条650000点）、MLII/同一map_adc、54点固定匹配容差、两秒启动计分、尾部不补零。不根据标签调时间偏移、删难记录、降低门槛或打开新独立测试。原始数据逐条校验官方SHA256、首值/长度/校验和；不是新独立评估。
