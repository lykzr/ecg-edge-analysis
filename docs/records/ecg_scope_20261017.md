# 2026-10-17：心拍分类、节律分析与疾病判断的范围澄清

用户在核对ADS1292R及作品简介后，询问四类心拍是否完整、能否据此检测疾病，并要求记录讨论结论。本记录保存概念与工程范围；不是新增功能的完成证明，也不把讨论过的候选方向自动加入当前验收。

## 当前四分类是什么

当前[冻结协议](../../data/cnn_expanded_v7_protocol.json)对单次心拍附近的波形及历史RR分类；分类目标不是完整的心脏疾病目录。

| 类别 | 当前协议包含的底层心拍符号 | 解释边界 |
| --- | --- | --- |
| N：非异位分组 | N、L、R、j、e：正常拍、左右束支传导阻滞拍、交界性/房性逸搏 | N是研究分组名，不能解释为心脏健康或没有异常 |
| S：室上性异位分组 | a、J、A、S：伴差异性传导的房早、交界性早搏、房早、室上性异位拍 | 不等于房颤，也不覆盖全部室上性心律失常 |
| V：室性异位分组 | V、E：室性早搏、室性逸搏 | 不等于室速或室颤，也不能仅据V分组区分其全部子类 |
| F：融合拍 | F：正常激动与室性异位激动的融合拍 | 不是房颤，也不是独立的疾病诊断名称 |

底层符号依据[PhysioNet官方标注说明](https://physionet.org/static/lightwave/doc/annotations.html)。常用AAMI研究分组还包含Q，通常归入起搏拍、起搏与正常激动的融合拍及无法分类的心拍，见[研究中的分类映射表](https://pmc.ncbi.nlm.nih.gov/articles/PMC4897569/)。当前工程没有训练Q，保持现有冻结四分类，不因记录本次讨论自动变为五分类。

四类不覆盖所有心拍类型；五大类同样是对具体类型的归并，不是全部心脏疾病。节律、ST/T改变等在官方数据库中有独立标注，不能由四个心拍标签完整表达。

## 能否根据心拍检测疾病

心拍形态、出现时序、心率、RR及连续心电可以提供部分心律异常线索。S/V标签可提示相应异位心拍，需要进一步结合具体类型、数量、连续性和节律分析，不能把一个类别直接对应成一种疾病。

房颤等节律异常需要分析连续心电，不能把S直接当房颤；临床诊断还结合病史、体检及必要的其他检查，见[NIH心律失常诊断说明](https://www.nhlbi.nih.gov/health/arrhythmias/diagnosis)与[房颤诊断说明](https://www.nhlbi.nih.gov/health/atrial-fibrillation/diagnosis)。心拍四分类也不能作为冠心病、心肌梗死等疾病的完整诊断。

讨论得到的功能层次为：采集ECG → 检测R峰并切拍 → 心拍分类 → 统计连续节律/异常事件 → 输出异常提示。当前实现仍停留在限定心拍任务的开发验证；连续节律模块的目标类别、窗口、标注、算法和验收条件尚未确定。不能把数据中存在节律标注写成工程已具备相应检测能力。

后续真实输入需要设计未知、不支持及信号质量不足的处理出口，并用对应数据验证。它们不是当前模型已具备的输出；增加Q或置信度阈值，也不能直接宣称已经解决全部未知输入。

## ADS1292R与作品简介的对应关系

ADS1292R可以承担心电采集前端：双通道、24位ADC、可编程增益、125—8000SPS输出及SPI接口；它输出数字波形，不自行给出N/S/V/F标签。500SPS是讨论中的可选采样配置，不是已经联调通过的工程参数。启用呼吸测量时，通道1不能同时用于ECG采集。依据为[TI官方产品页](https://www.ti.com/product/ADS1292R)及[Rev.C数据手册](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)。

具体模块原理图、电源/逻辑电平、电极与导联配置、输入保护和人体连接条件仍需核对。芯片具有ECG采集能力不等于当前模块和整机已经完成真实采集验证；换采集芯片也不能自动解决现有分类模型的跨人泛化。

用户提供的简介要求“采用轻量化1D CNN对心拍波形进行分类”，并包括采集、滤波、工频抑制、QRS/R峰、心率/RR、INT8、FPGA核心推理、实时显示及ARM/FPGA对比。明确限定N/S/V/F四类任务与该方向一致，不代表完整简介已经完成，更不能概括为全面心脏病诊断。

可采用的范围表述是“限定类别的心拍分析与异常提示”；“部分心律异常辅助筛查”是进一步明确并验证节律任务后的表达方向。模型/量化/PL及性能验收分别开展，核心AI与FPGA目标不因本次澄清被删除。
