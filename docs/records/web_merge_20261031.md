## 实施与取舍

- 在src/web保留来源青绿色网页、离线记录/详情/趋势/备注/家庭授权业务，新增“实时与板卡”。原src/ui的Tk和命令行入口继续保留；不是用离线模型替换板端算法。
- 新增src/pc/ecg_web_service.py，以适配层复用现有CaptureWorker、BridgeWorker、RuntimeWorker、Monitor/Recorder及USB身份记忆。支持演示、raw.log、只收结果、厂商CSV/34字节查看、厂商CSV/蓝牙中转、标准360/500Hz回放九种来源。
- 厂商帧、ECG-IN-1、ECG-UART-1分别解析。保留原码、源序号、原始日志和完整输出；单位未知不补造mV，类别能力缺失不显示N。标称换算沿用冻结合同，不修改QRS、采样率转换、分类合同或板端源码。
- 网页保留原始时刻做极值抽稀，缺口断线，raw/filt可分别或叠加显示；事件只映射到实际收到的源样本。修正来源波形抽稀后时轴挤压、末点时间、多图网格ID冲突、未知室早填0及历史会话来源选择不同步等问题。
- 实时API按账户限制会话/文件访问；只能上传后用凭证选文件，不接收任意服务器路径。刷新只枚举，启动前核USB身份，采集与Zynq不能占同端口，合法报文后才记忆身份。同一时刻只允许一个活动后台占用设备。
- 原WebSocket空入口接入认证快照，令牌放首条消息、同源检查、持续核对注销/过期，慢发送有超时。网页当前使用串行HTTP轮询，不声称浏览器已经改为WebSocket推送。页面关闭不暗中停采集，可回会话列表停止。
- 显示缓存4096点/256事件，单文件上传32MiB、累计256MiB/64文件，实际HTTP字节限额34MiB，原后台记录默认64MiB。离线任务内存队列改为128，满后保留SQLite pending，由空闲线程有界补取，不丢任务或无限堆内存。
- 会话快照/小型索引落盘，保留重启后历史；停止后等文件关闭再下载，保存失败可见。单进程回环地址运行，不默认加载、下载或训练模型。来源OpenECG精确500Hz校验，默认none；其离线零相位显示滤波与实时链路明确分开。
