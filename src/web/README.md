# 网页主客户端

普通“分析”及重复导入按账号、输入数据、处理代码和配置指纹复用已完成结果或进行中任务，不重复生成版本；结果详情的“重新分析”明确新建版本并保留旧结果。失败或取消的任务允许再次尝试。旧记录未保存配置指纹，不能追认与当前配置一致，因此首次按新规则分析可能建立带指纹的版本，之后复用。

分析详情、任务及测量查看页顶部提供返回入口；从列表进入时保留筛选条件。测量列表显示已保存的分析版本数；普通分析复用一致版本，明确“重新分析”才新增版本。分析统计不作为有效测量次数，基础质量检查也不代表分类成功。

实时页默认“实时采集”，可选择板卡处理或仅查看；“文件回放”另选厂商/标准CSV及360/500Hz，“演示”无需设备。仅接收板卡结果和原始日志回放在高级工具中。文件格式须与输入及板端程序匹配，不猜测采样率或单位。来源波形分别选择信号和单位；心电有标称电压时默认mV，厂商滤波及板端滤波仅在实际提供时出现。测量列表统一提供查看、分析和版本操作，错误详情可展开。

来源“信号”另提供实际存在的PC基线校正、节律显示滤波和呼吸显示滤波；旧记录缺处理列时不生成选项，也不补算。保留原始值，不按典型幅值归一化；显示处理不改变板端或模型输入。完整500Hz采集可在结束后另交电脑HGB研究模型分析，分析使用账号目录及同一去重/版本关联规则，共享测量保持只读。标准500Hz须明确hp05/raw；关闭模型时仍保留原有基础分析入口，不把演示或360Hz送入HGB。

账号数据统一位于 tmp/web_runtime/users/用户名--固定用户编号/。sessions/测量编号/保存测量原件、板卡结果与会话索引，其下analyses/任务编号/保存该次测量的分析输入与结果版本；直接导入的数据位于账号目录analyses/任务编号/。SQLite保留账号、权限与任务索引。用户名清洗并附固定ID防止目录冲突，程序不允许自行填写服务器文件路径。

登录默认进入实时页；主导航使用实时、导入分析、历史三个业务入口及家庭授权。概览旧路由保留为 /overview，不再占主导航。测量列表集中在历史页，可查看原始波形、发起分析及打开分析版本；导入页只处理新文件，提供前往历史选择测量的入口，分析详情可回到对应测量。统计区明确只统计分析版本，缺心率日期不跨日连线，无结果时显示空状态。详情和任务页保留一个顶部返回入口，返回保持历史筛选；导入期间锁定输入，选错文件会清空先前选择。家庭页支持刷新授权与通知。旧live/sessions目录兼容读取，与新目录同编号时去重；不会自动移动活动文件。当前测量列表最多100条，超出后需要后续分页支持。模板演示缺标定比例时不会猜测幅值进行分析；缺波形、序列缺口、进行中或超过离线点数上限会明确拒绝。

测量列表仅在历史页展示；实时页保留前往历史的入口及进行中会话的继续查看按钮。实时页选中会话后将编号保存到地址的 `session` 参数，刷新可恢复查看；离页不会停止服务端会话。家庭页可直接打开全部共享记录，通知显示授权人；重复授权复用有效授权，撤回后共享访问与通知同步失效。共享详情只读，导出、删除、重新分析和备注写入仅对本人开放。

本目录是日常使用的默认界面；[Tk客户端](../ui/README.md)仅作备用诊断与回归，切换前停止活动会话，不能共同占用串口。

本目录保存网页界面、账户/记录业务与本项目实时后台的适配。页面采用来源项目的布局；设备协议、采集和中转复用 `src/pc`，原Tk入口继续保留。

| 位置 | 职责 |
| --- | --- |
| frontend | React/TypeScript页面、波形与请求适配 |
| business_logic | FastAPI、SQLite账户/记录/授权/任务与实时API |
| ai_model | 默认HGB逐拍研究分类及解释，可显式关闭或选OpenECG节律适配 |
| signal_processing/python | 离线CSV和显示滤波，不替代板端实时处理 |
| hardware | 合成记录及ADS导出辅助，不采用上游固件协议 |
| run.py | 本机、单进程、同源网页启动入口 |

从项目根运行 `./build/build_web.ps1` 构建，再用独立环境执行 `python -B src/web/run.py`。环境建立、操作、数据目录与验收边界见[网页教程](../../docs/download_guide.md)；软件测试在 `sim/web`。[来源与许可](NOTICE.md)、[导入原始哈希](upstream.json)用于追溯；导入哈希是改动前的来源身份，不表示当前适配文件未修改。

测量列表明确显示所属用户名，默认仅本人；勾选“查看授权给我的记录”后按用户名排列有效授权人的测量。家庭授权允许查看测量波形与已完成分析，原始文件下载、SVG导出、停止及分析仍仅本人；每次读取重新校验授权，撤回后禁止后续访问。
