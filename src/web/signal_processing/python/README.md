# 离线信号处理

parse_csv支持单列mV及包含ecg_raw的厂商CSV；厂商原码依据冻结NominalConverter合同转换，保留参考电压、增益、分母和来源字段。未知ecg_filtered单位不能当mV。时间戳与声明采样率冲突时拒绝，不自动补点。

process检查有限值、长度、平直及突变，提供离线显示滤波：0.5至40Hz范围带通及可用时50Hz陷波，采用零相位双向处理。原始mV波形与处理波形分别返回；原始波形传给可选离线分类器，不偷偷替换训练预处理。

本模块不替代实时QRS、板端切拍或最终分类接口；实时数据由src/pc和现有PS程序处理。具体幅值合同与边界见[网页教程](../../../../docs/web_monitor.md)。
