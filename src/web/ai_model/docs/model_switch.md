# 离线分类配置

默认hgb：固定仓库v92/fold0，用完整500Hz单导联mV作逐拍N/S/VF研究分类。none显式关闭。可选openecg仍为另一项整段节律适配；严格500Hz、至少10秒，分析前10秒。两者任务不同，不自动替换、投票或做主备回退。

首次初始化会缓存适配器，配置修改后需重启。HGB独立进程按完整记录重建全部状态，最多200000点、4数值线程、180秒墙钟；超限返回不可用，不截断、不重试或转用其他模型。ECG_HGB_PYTHON可指定模型Python；权重/源码按清单检查，文件不符、程序或依赖缺失不输出类别。参见[本目录说明](../README.md)。
