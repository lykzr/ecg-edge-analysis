# 冻结360Hz运行时

本目录把研究26的冻结数学流程实现为裸机C候选：GQRS决策、原波形/模板复核、梯度辅助定位、72点确认等待、原波形切拍、360→144Hz模型窗口变换和RR输入。运行于Zynq ARM，不使用原PL检测器；PL保留未来最终INT8核心推理的目标，不因本移植取消。

- 输入严格为360Hz、4096单位/mV、int16，从0连续编号；不接厂商34字节帧，不接受500Hz或未知标定，不采用失败500Hz转换路线。
- 原始/辅助采样缓存4096点、GQRS滤波1024点、峰槽64、模板8、待确认/切拍队列32；RR历史401项（当前加过去400）。无无限历史、启动/尾部不补零。
- GQRS平滑和能量使用int64，形态/辅助滤波和窗口重采样使用double，模型张量float32；关闭浮点融合。不称INT8、全整数或FPGA核心已完成。
- pipeline.h返回128点窗口、标准化RR3、心拍号、位置/源时轴、无效状态；模型参数须由调用者绑定。当前串口应用没有最终模型，使用未绑定模型身份，输出CLASS NO_MODEL/未知，不声明CLASS_RESULT。
- 静态预留192KiB算法缓存；构建脚本配置128KiB应用栈和libm，不改PS7/DDR/MIO/时钟。main.c沿用已核UART/计时器接口，运行中接收溢出/校验/帧错误立即停止。
- link.c独立实现ECG-IN-1的360Hz/scale4096配置，返回ECG-UART-1 QRS26-ARM；旧500Hz应用源码和默认PC合同保留。接收新I前周期发送合法启动H，电脑收到就绪后才上传；此H不包含采样或检测结果。

构建/运行/复现见[板端说明](../../../docs/runtime_board.md)，原数学和接口见[运行时](../../../docs/qrs_runtime.md)、[分类接口](../../../docs/classification_protocol.md)。C实现派生WFDB4.3.1 MIT许可GQRS及本项目冻结版本；完整MIT版权与许可见[原许可](../../third_party/wfdb_license.txt)，源码身份见provenance.json。实做成绩、失败和限制集中docs/records。
