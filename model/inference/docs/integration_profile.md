每折训练用另外两组INCART患者及协议允许的MIT辅助训练数据。联调统一fold0不等于在所有开发患者上使用它计算独立验证分数；复算原交叉验证必须按患者对应留出fold。当前选取不是将历史最高macro-F1模型直接作为最终生产模型。

首选未额外滤波mV→hp05。高通为a=500/(500+2π×0.5)，b=[a,-a]、分母[1,-a]、float64，初始zi=[-a*x0]，首输出0。只有已逐阶段核对完全匹配该高通的数据，才选raw避免重复高通。不要把其他带通/陷波、厂商滤波列或网页零相位显示结果直接接入并沿用原评价。

与merge当前采集接口对照：CH2为ECG，接口文档标称2.42V/PGA6换算mV，参数实测标定仍由采集侧核定。模型不再次按ADC增益换算；4096 codes/mV仅为内部模型标度。若接的是电脑已高通后的int16模型码，先明确其标度及高通状态，不能将码值直接作为mV传给infer_mv。

普通连续传输分块必须延续高通、检测、RR、背景与待处理状态；断流缺样/时轴不明、重连、重启、导联或增益切换应开新会话并重置。当前整段API每次调用重建状态，不能把小块独立调用后拼起来冒充连续处理。

系统侧继续处理实时跨块、网页适配与Zynq事件对应。本次仅合入完整可运行模型模块，网页的默认none/OpenECG选择和未知分类语义保持；没有自动替换正式分类器、修改采集或写板卡。模型与网页依赖分别管理，模型已验证Python3.12/NumPy2.2.6/SciPy1.16.2，网页原环境为Python3.14。
