# 模型接入说明

## 输入和输出

入口接收一条完整连续记录，500Hz、单导联、单位mV。开发核对使用II导联；ADS1292R实际导联、ADC增益、参考电压、符号和时间连续性由采集模块核定。此包不把原始24位ADC码当mV，也不自动猜测单位。源码里的4096 codes/mV只是公开数据回放的内部模型码值标度。

```python
from adapter import analyze_ecg

# samples_mv是一维mV数组；fold必须由调用方明确指定。
result = analyze_ecg(samples_mv, fold=0, preprocess="hp05", sampling_hz=500)
```

后端将整个解压目录放入vendor，随后把该目录加入模块路径即可导入adapter。不需要joblib、scikit-learn、WFDB、PyTorch或模型训练环境。返回值可直接json.dumps(..., allow_nan=False)：无效拍的probabilities为None，label为UNCLASSIFIED，class_id为-1。

若需要逐维检查，使用`from ecg_model import infer_mv`。同名参数下返回features（n×192）、requests、positions500、ready500、decision_at、valid、probabilities等NumPy数组。不要将原始mV直接传给树评价函数；也不要把128点归一化波形当成192项特征。

每次调用重建检测和RR/背景状态，适合整段记录回放与电脑端联调。**不能把相邻实时小块各自独立调用后拼起来，声称等于连续流。** 后续实时服务需要维护跨块状态、样本序号、丢样和重启协议；当前未改队友服务，未完成真实网络/串口联调。

## 预处理必须明确选择

| 参数 | 行为 | 接入条件 |
| --- | --- | --- |
| hp05 | 对mV做因果0.5Hz一阶高通，再按模型码值量化 | 对应既有hp05研究评价；建议先用未作该高通的mV回放验证 |
| raw | 不添加此高通，直接量化 | 用于原始模式对照或明确已完成匹配预处理的数据；不代表任意滤波均兼容 |

队友已有开源滤波可能含不同高通、低通、陷波、零相位或整段标准化。不能直接在其输出上再次hp05，也不能仅选择raw便断言输入已与训练一致。先导出同一段未经额外处理的mV与滤波后mV，核对采样率、幅值、时间轴和实际滤波配置，再决定正式适配；本包不替换其采集/滤波实现。

量化采取半值远离零舍入并饱和到int16。输出clipped_samples保留被饱和的样本数。当前只支持500Hz，不将其他采样率静默当成500Hz，也不内部补丢样。

## 固定流水线

1. mV可选hp05高通→4096 codes/mV int16。
2. 原冻结C检测器：500→360有理FIR（1001系数、18/25），内部检测后映射回500Hz时轴。采用team/system快照59cc666，未改变队友原文件。
3. 模型侧固定斜率平方能量重心校正位置，使用内部±36点；最右所需样本必须已经到达原报告时刻，不按标签调整位置，不增删或排序事件。
4. 按新位置重新计算等待、RR与完整窗：R前178点、从R开始267点，共445点；2501系数36/125重采样及固定插值生成144Hz网格上的128点，去均值，标准差下限0.05。
5. 当前R之前已完成报告的最后8个完整窗口生成中位背景；不使用模型预测或专家标签筛选历史。
6. 原形态/RR/相对背景/频带159项＋有界后继RR 7项＋因果节律12项＋固定Hermite14项=192项。具体顺序以assets/feature_names.json为准。
7. 读取指定fold的原v92参数，64轮×3类=192棵树，输出N/S/VF概率。没有拟合、阈值搜索或默认三折投票。

检测与切拍分别由两个原生程序实现，不能把recut500说成检测器。1001系数用于检测采样率转换，2501系数用于模型波形窗口转换，两者不可互换。

## 时序与状态

输出r_sample500从0开始；r_seconds=r_sample500/500。waveform_ready_sample500是窗口已准备时刻，decision_sample500包含对下一已报告事件的有界等待；最大等待从R位置计1250点（2.5秒），并受记录结束限制。两者均是样本时间轴，**不是电脑运算耗时或板上延迟实测**。

| input_status | 含义 | 分类输出 |
| --- | --- | --- |
| 0 | 完整输入、RR已知 | 输出N/S/VF及三类概率 |
| 2 | 第一拍RR未知 | UNCLASSIFIED，不强制算N |
| 4 | 记录边界等造成窗口不完整 | UNCLASSIFIED，不补样、不删事件 |

记录末尾只结束已有待切事件，不为检测器补造未来信号。缺少下一拍时后继特征按冻结超时规则置零，不能偷用未来标注。

## 三个fold怎样使用

三个参数是原患者隔离三折模型，未做最终全开发集重新拟合。集成示例明确使用fold0以检查接口，**不是推荐fold0效果最好**。任何已看过开发病例可能属于其中某折训练患者；如重新复算交叉验证成绩，必须沿用原患者到折的映射，而不能对每个人选择最优fold。包内三折全量数值核对只验证实现一致性，没有据此发布新的准确率。

OpenECG的记录级节律接口与这里的逐拍N/S/VF不是同一任务；若网页同时展示，应注明结果层级和模型来源，不把标签直接互换。INT8、PL树遍历、板上内存/性能、真实ADS输入、网页端到端效果尚未验证。
