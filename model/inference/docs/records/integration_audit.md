检查日期：2026-10-31。检查对象：本人工作分支feature/ecg-model中的完整电脑端模型模块，不是main或FPGA镜像。结论：**原始心电到192项特征的交接缺项已在本地源码和ZIP中补齐，原有模型识别质量仍未通过全部目标。**

## 1. 问题与处理

队友指出的缺项成立。之前推送的data/model_review只提供权重、特征名称、历史评价与合成特征核验，接收方无法仅靠它把原始mV心电转换成模型输入。无需重复训练，但必须交付实际预处理、检测、重定位、重切、RR/背景/后继时序与特征代码。

新增src/model_inference完整自包含目录。ZIP顶层为ecg-model-integration，包含Python入口、全部实际特征模块、C检测/切拍源码及Windows x64主机程序、三份原v92权重、FIR/Hermite常量、输入配置、示例、自检和第三方许可。源码读取自身目录定位资源，没有运行时tmp、原仓库盘符、用户名、训练缓存或专家标注依赖。

## 2. 交付接口

| 项目 | 约定 |
| --- | --- |
| 原始入口 | 500Hz、连续单导联、一维mV；CSV无标题单列，或一维NPY |
| 类别 | N / S / VF；VF仅原V/E/F合并，不是心室颤动 |
| 模型 | 原v92 HGB三份外折权重，调用方显式指定fold；没有默认投票或新正式模型 |
| 预处理 | 明确raw或hp05；hp05为冻结因果0.5Hz一阶高通，不能与队友未知滤波重复叠加 |
| 特征 | 159形态/相对背景/频带/RR＋7后继＋12因果节律＋14 Hermite，共192 |
| 边界 | 第一拍RR未知、窗口不足均保留事件并输出UNCLASSIFIED；不补样、不强制算N |
| 时序 | 输出R位置、窗口完成时刻与包含有界后继等待的决定时刻；不等于运算耗时 |
| 后端入口 | adapter.analyze_ecg，返回JSON安全结果；未修改队友服务 |

每次调用对应一条完整连续记录，检测及历史状态在调用间重置。此版本支持整段回放/电脑联调，不支持把实时相邻小块分别独立调用后拼接为等价连续流。4096 codes/mV是内部回放标度，不是ADS1292R的真实ADC增益。实际导联、标度、采样连续性和已用滤波仍需在整机中确认。

## 5. 接收步骤

1. 解压整个ecg-model-integration目录，先读README.md和docs/integration.md。
2. 用具备NumPy2.2.6、SciPy1.16.2的Python3.12运行`python -X utf8 -B check.py`，预期passed为true、models为3、features为192、fits为0。
3. 用run.py运行examples/synthetic500.csv，或后端导入adapter.analyze_ecg；明确指定fold与preprocess。
4. 接真实mV前核采样率、单位、导联、丢样和滤波；保留输入、R位置、状态和概率，与同段回放逐拍核对。

Windows x64主机程序已包含，无须为了运行此包安装GCC。全部C源码及build_native.py也随包保留；源码重建不会写板卡。包不含数据集、虚拟环境、工具安装包、整套tmp、Vivado缓存、Git历史或未授权原资料。
